## Weather Forecast Script

A new script `scripts/weather_forecast.py` fetches current weather data from the OpenWeather API.

### Requirements

- Python 3
- `requests` library (`pip install requests`)
- Set environment variable `OPENWEATHER_API_KEY` with your OpenWeather API key.

### Usage

Run the script with a city name:

```bash
python scripts/weather_forecast.py Paris
```

The script outputs the current weather for the given city in French.
